The framework

The web stack,
with less in the way.

Anvil is a server-rendered .NET framework built on ASP.NET Core and Razor. It gives pages, routes, and request context a focused home — then stays out of your way.

01Rendering

Razor pages that
start close to the user.

Keep your UI server-rendered, close to the route that owns it. Anvil discovers component routes through ASP.NET Core and gives you layouts, partial HTML updates, and a straightforward place to put page behavior.

Request lifecycle

Three clear steps
from URL to HTML.

Anvil keeps the request path legible. A route identifies the page, the request context gathers what the page needs, and Razor renders the response.

02Request context

A useful home for
the current request.

RequestContext exposes the work you repeatedly need: cookies, sessions, route links, application services, memoized data, and authorization checks. The API stays close to ASP.NET Core instead of hiding the platform from you.

var products = await request.MemoizeAsync("products", LoadProductsAsync);
03Typed routes

A URL is a contract,
not a string.

Keep route values in a dedicated record and let Anvil generate links from the same definition. Route encoding, query values, fragments, and current-route checks are part of the shape.

public sealed record ProductRoute(int Id);
var href = ProductDetails.Link(new ProductRoute(42));

Getting started

Your first Anvil app
is closer than you think.

Anvil's CLI creates the shape of an application for you, so you can spend your first minutes on a page instead of a pile of setup files.

Before you begin

Bring a .NET 10 SDK
and a few quiet minutes.

Install the Anvil CLI as a global .NET tool, then use it to create your first application. Anvil is currently in early preview, so check the package page for the latest release and requirements.

dotnet tool install --global Raukeld.Anvil.Cli

View Raukeld.Anvil.Cli on NuGet ↗
Then run anvil new Portal, enter the project, and start it with anvil dev.

The short version

Three commands
to a running app.

01

Create

Generate a new application with the Anvil CLI.

anvil new Portal
02

Enter

Move into the project that Anvil created.

cd Portal
03

Run

Start the development server and open your new app.

anvil dev

Your first page

A route, a layout,
and something real.

Generated projects use Razor conventions, so a page can be small and still feel like a proper application. Start with the framework's defaults; add more only when your product asks for it.

Conventions that
leave room for you.

Generated projects can start from the default or Identity profile. The CLI initializes the project, restore flow, migrations, generated manifests, and first build so the folder structure has a reason to exist.
